# ✨ 星记事 · Star Notes

优雅的本地记事本：自动记录时间与网络 IP，多账号登录，内置聊天、好友、私聊与管理员系统。

## 🎮 在线访问

👉 https://xingyuan170-hub.github.io/star-notes/

## 功能

| 模块 | 说明 |
|---|---|
| 📒 记事本 | 自动记录创建/编辑时间 + 公网/局域网 IP，输入即自动保存 |
| 🔐 账号系统 | 注册/登录，SHA-256 加盐哈希，多账号 |
| 💬 群聊 | 发消息、发文件（txt/docx/ppt/bmp/xlsx/py/accdb/sh，≤20MB，5 天过期）、发记事内容 |
| 👥 好友 | 搜索账号、验证消息（≤15字，7 天过期）、加好友后解锁私聊 |
| 💬 私聊 | 任意格式文件 ≤30MB |
| 🔔 通知 | 未读红点、一键已读、新消息提示音 |
| 🛡 管理员 | 主管理员（金色👑）可封禁/禁言/删群消息/授予管理员；普通管理员（蓝色💠）限时禁言与限额删除 |
| 🌓 主题 | 亮色 / 暗色一键切换 |

## 技术

- 单文件 HTML + Canvas-free 纯 DOM，零依赖
- 存储：localStorage（账号/记事/聊天/好友）+ IndexedDB（文件 Blob）
- 存储层已做适配隔离，后续可平滑切换服务器同步
- ⚠️ 当前为纯本地模式：数据存在各自浏览器中，跨设备聊天同步（服务器版）开发中
